Build a complete, modern, responsive web application called **CampusBite – Canteen Pre-Order & Token Management System**.

The application is for a college/office canteen. Customers should be able to browse the menu, place food orders, automatically receive a token number, and track their order. Canteen staff/admin should be able to manage menu items, view incoming orders, update order statuses, and operate a live token display screen.

The application should be fully functional, not just a UI prototype.

## 1. TECHNOLOGY STACK

Use:

* Frontend: React + TypeScript
* Styling: Tailwind CSS
* Backend: Node.js + Express
* Database: SQLite for the initial version
* ORM/database library: Prisma or an appropriate SQLite-compatible solution
* Authentication: Secure session/JWT-based authentication
* Icons: Lucide React or another clean icon library
* Charts: Recharts if needed
* QR code: A suitable QR-code library
* Use environment variables for secrets
* Make the application easy to run and deploy on Replit

Keep the architecture clean and modular.

## 8. AUTOMATIC TOKEN NUMBER GENERATION

This is a CORE feature.

After an order is successfully placed, automatically generate a token number.

Tokens should be sequential for each business day.

Example:

First order:
#001

Second order:
#002

Third order:
#003

...

100th order:
#100

The token counter should reset automatically on a new day.

DO NOT simply generate a random number.

The backend must guarantee that two simultaneous orders cannot receive the same token.

Use a database-safe approach/transaction for token generation.

Store:

* token number
* order ID
* date
* status

Display the token prominently after checkout.

Example:

---

ORDER CONFIRMED 🎉

Your Token

#042

Order ID:
ORD-2026-00142

Pickup:
12:45 PM

Status:
Order Placed

## [Track Order]
